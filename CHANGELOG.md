# goodfellow-language-fr

## 0.2.0

### Minor Changes

- 7d600f8: Translates everything Goodfellow 0.10 adds to the admin panel, 143 strings in all: setting up Sign in with GitHub, GitLab or Bitbucket on the Security tab, exporting as Markdown, and moving content to and from another Goodfellow site. The Import / Export tab's name, whose English changed, is translated again.
- d50ee04: Translates everything Goodfellow 0.11 adds to the admin panel, 53 strings in all: publishing new pages, which now start out not published, updating installed blocks, the AI assistant's free services and its reports, Site Settings' Free services list, the editor's drag handle, and the page settings' new groups. Three strings whose English changed are translated again, and the Item field block, Entry field's new name, keeps its French. Strings whose English only gained a comma before "and" or "or" keep their French, which doesn't use one.
- 6e825bb: Translates everything Goodfellow 0.9 adds to the admin panel, 304 strings in all: kept changes, links to items and the new kinds of field, the media library's descriptions, focal points, tags, cropping and selecting several files, synced blocks, visit counts, your own fonts, keyboard shortcuts and Go to, downloading a copy of the site, importing Markdown folders, Netlify, and the new blocks' settings. Three strings whose English changed are translated again.

### Patch Changes

- 8c90861: Keeps the French for four labels that Goodfellow 0.11 reworded, so sites on 0.9 and 0.10 still show them in French.
- 9712143: Links to Goodfellow's GitHub Sponsors page from npm.
